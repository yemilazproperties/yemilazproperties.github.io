YEMILAZ PROPERTIES — SETUP

1. Unzip this package into the root of your yemilazproperties.github.io repository.
2. For the existing Yemilaz Properties Supabase project, run supabase/property-images-migration.sql in SQL Editor before redeploying. It adds the property fields required by this website and configures private property-photo storage. Keep existing rows.
3. In Supabase Auth > URL Configuration, add https://yemilazproperties.github.io/** and http://localhost:8000/** to Redirect URLs. Set the production URL as Site URL.
4. Set up SMTP in Supabase Auth so tenant/caretaker invitation emails can be delivered.
5. Deploy invite-member and notify-agreement Edge Functions. See README.md for CLI commands and Resend secrets. Never put service-role keys in this GitHub repository.
6. Review the files in GitHub Desktop. Commit to main and push. GitHub Pages should publish from main / (root).
7. Visit https://yemilazproperties.github.io/ and sign in. Local testing: run `python -m http.server 8000` in PowerShell from the project folder and open http://localhost:8000.

config.js contains the Supabase project URL and publishable browser key. Publishable keys are intended for browser use; all private data is protected by Supabase RLS.
